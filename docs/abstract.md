# Abstract

**ResumeFit AI: An Explainable AI-Based Job-Specific Resume Evaluation, Gap Analysis and Optimization System for Final-Year Students**

Final-year students and freshers often apply to many roles with a single generic resume and receive little actionable feedback on how well it matches a specific job description. Existing resume checkers commonly report opaque keyword-based scores, reward keyword stuffing and, when large language models are used for rewriting, risk introducing claims the candidate cannot support. This project presents ResumeFit AI, a web-based system that evaluates a real PDF or DOCX resume against a specific job description and explains every point of the result. After file validation and text extraction, a rule-based natural language processing pipeline built on a curated skill ontology converts the resume and the job description into structured representations, and each job requirement is matched against resume evidence graded as high, medium or low strength. A deterministic, versioned scoring engine then produces three independent scores, Job Fit, ATS Readiness and Resume Quality, with an itemised list of lost points that sums exactly to the shortfall from 100. Gap analysis separates missing, weakly evidenced and only partially related skills. Optimisation is provided through rule-based fix suggestions protected by a fabrication guard: new claims require placeholders and explicit user confirmation, and an optional language model is used only for guarded rewording, never for scoring. Every edit creates an immutable resume version that is re-scored by the same engine for before-and-after comparison. In a small synthetic, single-annotator evaluation against keyword, TF-IDF and sentence-embedding baselines, the ontology engine achieved the highest observed requirement-detection F1 (0.969) on the constructed evaluation dataset. The system also supports interview preparation and application tracking.

**Keywords:** resume evaluation, job description matching, explainable scoring, skill ontology, gap analysis, applicant tracking systems, fabrication guard, natural language processing, final-year students
